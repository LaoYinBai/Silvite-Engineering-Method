# Runtime Isolation, Cleanup, and Relocation Gates

本文件约束 Agent 在诊断、整理、隔离、迁移或卸载宿主机与运行时环境时的操作行为。本文件只定义**操作红线与验证门禁**，不规定特定机器的目录布局或具体项目路径。

## 1. 先盘点、先对齐、再动手

执行任何清理、迁移或删除前，先只读完成现状盘点并与用户确认方案：

- **全局与基层现状**：记录系统/用户 `PATH` 顺序、重复条目、疑似空壳（stub）入口、管理器基础环境（如 `base`）内的业务包分布。
- **并行与重复运行时**：识别同一工具或服务在多套管理器间并存的实例，核对其数据、入口与实际使用者后再决定收敛方案。
- **活跃消费者清单**：全量扫描后台进程、系统服务、MCP/IDE 配置、自动化脚本与跨环境硬链接，明确每个运行时的消费者。仍有活跃外部依赖的运行时标记为受保护保留项，不得误删。
- **真实可释放空间审计**：清理包缓存前，使用管理器 `--dry-run` 区分“可重建纯缓存”与“跨环境硬链接共享文件”，不以目录逻辑大小误判可删空间。

## 2. 宿主机底座极简与防反向污染

整理环境时，宿主全局层与基础运行时只保留跨项目刚需底座（OS 基础目录、基础 CLI、包/环境管理器自身入口）：

- **业务进独立隔离环境**：项目依赖、科学计算或工具运行时不混装进宿主机全局或管理器 `base`。
- **禁止子环境反向泄漏**：严禁把特定子环境的动态库目录、`Scripts`/`bin` 或工具内部捆绑的私有子链（如内置 `git`、`usr/bin`）永久写入宿主机全局 `PATH`。
- **消除入口劫持**：确保系统唯一真源入口排在 OS 应用商店空壳（stub）、重复条目和临时工具目录之前。

## 3. 混装环境清理与防误装护栏

同一环境混用过“主环境管理器”（如 Conda/OS 包管）与“二级包管理器”（如 `pip`）时：

- **批量卸载后的双向自检**：卸载二级包后，必须立刻验证主管理器自身核心命令/入口可无警告运行，并执行二级依赖一致性检查（如 `pip check`）。若二级卸载连带移除了曾被覆盖的共享底层依赖（如 `cffi`、`click` 等），立即通过主管理器补回官方依赖。
- **护栏作用域对齐**：使用全局防误装护栏（如强制虚拟环境才允许二级安装）保护 `base`/全局时，必须核查环境管理器激活变量与护栏检查变量的语义是否一致；通过**环境级作用域变量**为合法隔离环境精准放行，避免护栏反过来阻塞隔离环境。

## 4. 不可移动前缀迁移与“旧路径幽灵存活”门禁

包含绝对路径绑定（二进制启动器/wrapper 内嵌路径、shebang、`pyvenv.cfg`、包元数据、Shell init 钩子）的环境**严禁通过直接移动或剪切目录搬迁**。

### 强制迁移顺序

1. **备份前态**：保存环境变量、管理器配置、Shell Profile 及各环境包清单快照。
2. **重定位默认配置**：更新环境管理器的默认环境目录、包目录与缓存目录配置。
3. **新位置克隆或重建**：在目标位置建立新环境。
4. **旧前缀零残留审计与重绑（脱钩门禁）**：扫描新环境入口（可执行包装器、脚本、`*.pth` 与配置文件），重绑所有仍指向旧前缀或历史过期前缀的硬编码路径，直到旧前缀命中数为 `0`。
5. **切换上层引用并独立验证**：更新相关调用方的显式环境入口，验证新环境独立可用。
6. **删旧与复验**：移除旧环境与多余缓存后，再次验证关键入口与真实运行结果。

### Ghost-Dependency Gate（防幽灵存活）

旧环境尚未删除时，哪怕新环境里的可执行启动器仍硬编码回指旧环境路径，命令探测依然可能“表面通过”，一旦删除旧环境即刻全面失效。因此：**未完成新环境入口的旧前缀零残留扫描与重绑前，禁止删除旧环境。**

## 5. 跨持久化表面的彻底退场

当要求“彻底清理/卸载干净”某个工具或环境时，跑完包管理器卸载或删除主目录不等于完成。必须逐面清零并保留扫描计数证据：

1. 包管理器全局安装记录；
2. 磁盘程序目录、工作目录与残留缓存/数据目录；
3. 用户级与系统级环境变量（含 `PATH`）；
4. Shell Profile 与初始化钩子；
5. OS 注册表、启动项、计划任务与后台服务；
6. 在新开多种目标 Shell 中验证目标命令解析为 `NOT_FOUND`。

## 6. 权限边界阻断时的降级交付

当某层整理操作需要系统级/管理员权限（如修改系统级 `PATH`、受保护注册表或系统服务），而当前会话权限不足或提权通道受阻时：

- **严禁绕过权限检查**或使用非授权通道；
- **停止该层写入**，保留该层原始状态备份，并在最终报告中如实标记为 `Blocked` / 未执行；
- 可输出一份**带前置条件、数量校验与关键系统路径断言**的可审阅本地脚本，交由用户在合法提权终端审阅后执行。

（涉及 `PATH`、环境变量或 Shell 初始化变更的冷验证细则，见 [topology-and-lifecycle.md](topology-and-lifecycle.md)。）
